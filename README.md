# External Sort
External sorting algorithm implementation in Java using a heap.

## Project 🌳
```
.
├── Heap.java
└── XSort.java
```

### Usage
Compile and run with an input file of lines to sort:
```bash
javac XSort.java
java XSort < input.txt
```

## Commands
1. To run the sort use `java XSort < input.txt`.
